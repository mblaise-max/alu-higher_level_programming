# Python - More Classes and Objects

Project about OOP in Python 3: properties, class attributes, special methods
(__str__, __repr__, __del__), static methods and class methods.

## Files
- 0-rectangle.py: empty Rectangle class
- 1-rectangle.py: width and height with validation
- 2-rectangle.py: area() and perimeter()
- 3-rectangle.py: printing with #
- 4-rectangle.py: repr() usable with eval()
- 5-rectangle.py: message when an instance is deleted
- 6-rectangle.py: number_of_instances class attribute
- 7-rectangle.py: print_symbol class attribute
- 8-rectangle.py: bigger_or_equal static method
- 9-rectangle.py: square class method
