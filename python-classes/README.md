# Python - Classes and Objects

Project about OOP in Python 3: classes, instances, private attributes,
properties (getters/setters), methods and validation.

## Files
- 0-square.py: empty Square class
- 1-square.py: Square with a private size
- 2-square.py: size validation (TypeError / ValueError)
- 3-square.py: area() method
- 4-square.py: size property getter and setter
- 5-square.py: my_print() prints the square with #
- 6-square.py: position attribute and positioned printing
