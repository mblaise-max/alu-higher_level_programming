# python-data_structures

This project covers Python lists, tuples and basic data structures.

## Tasks

- 0-print_list_integer.py: prints all integers of a list
- 1-element_at.py: retrieves an element from a list
- 2-replace_in_list.py: replaces an element of a list
- 3-print_reversed_list_integer.py: prints a list of integers in reverse
- 4-new_in_list.py: replaces an element in a copy of a list
- 5-no_c.py: removes all c and C from a string
- 6-print_matrix_integer.py: prints a matrix of integers
- 7-add_tuple.py: adds 2 tuples
- 8-multiple_returns.py: returns the length and first character of a string
- 9-max_integer.py: finds the biggest integer of a list
- 10-divisible_by_2.py: finds all multiples of 2 in a list
- 11-delete_at.py: deletes the item at a specific position in a list
- 12-switch.py: switches the values of a and b
