# python-exceptions

This project covers try/except/finally and raising exceptions in Python.

## Tasks

- 0-safe_print_list.py: prints x elements of a list safely
- 1-safe_print_integer.py: prints an integer with "{:d}".format()
- 2-safe_print_list_integers.py: prints the first x elements of a list, only integers
- 3-safe_print_division.py: divides 2 integers and prints the result in finally
- 4-list_division.py: divides 2 lists element by element
- 5-raise_exception.py: raises a type exception
- 6-raise_exception_msg.py: raises a name exception with a message
